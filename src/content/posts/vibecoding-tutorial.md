## 什么是 Vibe Coding

Vibe Coding 翻译过来就是"氛围编程"，核心思想一句话概括：

> **你只管描述想要什么，AI 负责把代码写出来。**

传统编程流程：想需求 → 查文档 → 写代码 → 调试 → 搜 StackOverflow → 改代码 → 重复…这个过程对新手极度不友好，一个分号写错位置就能卡你半天。

Vibe Coding 流程：用自然语言描述需求 → AI 生成代码 → 你验证效果 → 不满意就继续对话调整 → 搞定。

### 它不是魔法，是工具正确使用

Vibe Coding 并不是 AI 替代了程序员，而是把编程的**抽象层级提高了**。你不用关心 `Array.prototype.reduce` 怎么用，只需要说"帮我把这个数组里所有价格加起来求总和"。

打个比方：

| 传统编程 | Vibe Coding |
| :--- | :--- |
| 你需要知道方向盘、油门、离合怎么配合 | 你只需要说"去市中心" |
| 你得自己修发动机 | 车坏了 AI 帮你诊断，你点确认就行 |
| 驾照要考科目二科目三 | 有基本的方向感就够了 |

### 先决条件

在开始之前，只需要两个预备知识：

1. **逻辑思维** — 能把一个需求拆成步骤说清楚。比如"点登录按钮 → 验证账号密码 → 成功就跳转首页"，这就是最基本的逻辑。
2. **基本的文件管理能力** — 知道什么是文件夹、怎么打开终端/命令行。

就够了。不需要学过任何编程语言，也不需要理工科背景。

## 你需要准备什么

硬件软件都很简单：

### 软件

- **电脑**：Windows / Mac / Linux 都行
- **一个 AI 编程工具**，推荐以下几款，选一个就好：

| 工具 | 特点 | 适合人群 |
| :--- | :--- | :--- |
| Claude Code | 终端运行，功能最全，自主执行能力强 | 想深度使用 AI 编程的人 |
| Cursor | VS Code 改的，图形界面友好 | 习惯 IDE 操作的人 |
| Windsurf | 另一个 AI IDE，适合新手 | 刚接触编程的人 |
| GitHub Copilot | 嵌入 VS Code 等编辑器的插件 | 已经在用 VS Code 的人 |

- **Node.js** — 大多数前端项目都需要，[nodejs.org](https://nodejs.org) 下载安装即可
- **一个代码编辑器** — VS Code（免费）是最主流的选择

> 如果你不知道该选哪个，建议**先装 Cursor**。它是图形界面，跟普通软件一样双击打开，新手最容易上手。

### 心态

- **耐心** — AI 不是每次都能一次生成完美代码，可能需要来回调整几轮
- **好奇心** — 愿意尝试和实验，不害怕报错
- **基本英语** — 很多技术名词是英文的，但你不流利没关系，AI 工具都能用中文跟它对话

## 第一课：搭环境

我们以 Claude Code 为例。你不许笑，这可是专业人士也在用的工具。

### 安装 Claude Code

打开终端（Windows 按 `Win+R` 输入 `cmd` 回车，Mac 打开"终端"应用），输入：

```bash
npm install -g @anthropic-ai/claude-code
```

等待安装完成。然后在终端输入：

```bash
claude
```

第一次会弹出浏览器让你登录 Anthropic 账号，登录完就 OK。

### 创建你的第一个项目文件夹

在终端里：

```bash
mkdir my-first-app
cd my-first-app
code .
```

最后一行会用 VS Code 打开当前目录。

### 初始化项目

在 Claude Code 对话中，直接说：

> "帮我创建一个最简单的网页项目，能显示 Hello World"

Claude Code 会自动创建 `index.html`、启动开发服务器，告诉你打开浏览器看效果。

你不需要知道 HTML 是什么，也不需要理解 `<!DOCTYPE html>` 是什么意思——AI 会帮你搞定所有细节。这就是 Vibe Coding 的精髓。

## 第二课：用 AI 写第一个功能

现在我们来做个稍微实用点的东西——**一个待办事项（Todo List）应用**。能添加任务、勾选完成、删除任务。

### 描述你的需求

在 Claude Code 里说：

> "帮我做一个网页版的待办事项工具，要求：
> 1. 有一个输入框和一个添加按钮
> 2. 添加的任务显示在下方列表中
> 3. 每个任务可以勾选标记为完成，完成的显示删除线
> 4. 每个任务有删除按钮
> 5. 界面好看一点，不要花里胡哨"

你不会知道具体该用哪个框架，也不知道该怎么起手，没关系——AI 会帮你做判断，选 React、Vue 还是纯 HTML。

### 验证效果

AI 生成代码后，通常会告诉你如何运行。一般是：

```bash
npm run dev
```

然后在浏览器打开 `http://localhost:5173` 就能看到效果。

### 迭代完善

假设用起来发现"删除按钮太靠近勾选框容易误触"，继续提需求：

> "删除按钮和勾选框间距拉大一点，删之前弹个确认框"

AI 会修改代码，你刷新页面就能看到更新。开发效率比传统方式快得多：

在以前，新手要实现"删除前弹确认框"这个需求：搜索"JavaScript confirm 弹窗" → 找代码片段 → 粘贴 → 不知道怎么引用自己的删除函数 → StackOverflow 问 → 等回复 → 终于搞定。在 Vibe Coding 模式下，一句话说完 10 秒就搞定了。

## 第三课：让 AI 帮你修 Bug

写代码难免出 Bug，区别在于在 Vibe Coding 模式下**你不需要自己排查**。

### 碰到 Bug 怎么办

直接告诉 AI 你看到了什么：

> "点删除按钮没反应，控制台报错：Uncaught TypeError: Cannot read properties of undefined"

把报错信息原样贴给 AI 就行，不需要自己理解。AI 会分析错误原因并修复代码。

### 看不懂代码也能提需求

哪怕一行代码都看不懂，你照样可以用自然语言提升功能：

> "任务多了列表太长，能不能加个搜索框过滤？"

> "能不能给任务加个优先级颜色？高优先级红色，中优先级黄色，低优先级绿色"

> "能不能把数据存到浏览器里，刷新了任务还在？"

每一项都是实际开发中需要相当经验的功能。但在 Vibe Coding 模式下，你就像产品经理给开发下达需求——宏观把控即可，细节交给 AI 处理。

## 第四课：迭代你的项目

到了这一步，你已经有了一个基本可用的 Todo 应用。接下来可以考虑让 AI 帮你不断扩充功能：

### 增加标签分类

> "给每个任务加个可自定义的标签分类，比如'工作'、'生活'、'学习'，用不同颜色区分"

### 增加截止日期

> "每个任务加一个截止日期选择器，快到期的任务自动标红提醒"

### 部署上线

> "帮我把这个项目部署到 Vercel 上，让任何人都能访问"

如果项目配置了 Vercel 集成，Claude Code 会自动完成部署流程——认证、构建、发布一条龙。

### 持续升级的节奏

Vibe Coding 的开发流程呈现一种独特的"螺旋上升"模式：

每个"螺旋层"意味着版本在快速迭代。你不需要等待"掌握技能"，而是靠 AI 帮你扩展边界。一个零基础的人用这个流程，可以在几天内搭建出包含用户登录、数据库存储、在线支付等功能的完整应用，这在传统学习路径上需要至少几个月。

## 常见坑与避坑指南

新手用 Vibe Coding 最常踩的坑：

### 坑 1：需求太模糊

> ❌ "帮我做个网站"

> ✅ "帮我做一个个人博客网站，首页显示文章列表，点击文章进入详情页，分类按标签筛选"

AI 不是读心术专家。描述越具体，结果越精准。

### 坑 2：一口气提太多

> ❌ "帮我做一个像淘宝一样的电商平台，包含用户系统、商品管理、购物车、支付、物流跟踪、评价系统、IM 聊天…"

> ✅ 先做商品展示和购物车，做好了再慢慢加功能

大项目不断肢解成小目标。让 AI 一次只做一件事，质量会明显更好。

### 坑 3：不验证就继续加功能

每让 AI 加一个新功能后，先在浏览器里试一下是否正常。如果在错误的基础上继续加代码，问题会像滚雪球越滚越大。

### 坑 4：害怕报错

红色报错信息看着吓人，但大多数时候就是差个依赖没装或者少个半括号。直接把整个报错信息复制给 AI 就行，不用自己研究，AI 读报错比你快多了，更不用因此紧张。

### 坑 5：代码看不懂就放弃

完全看不懂 AI 写的代码很正常——如果你本来就不是程序员，那有什么好奇怪的？你不需要成为代码大师，只要能描述清楚需求和验证功能是否正常就够了。看懂代码是加分项，不是必选项。

## 下一步学什么

当你用 Vibe Coding 完成了 2-3 个小项目后，你可能会发现自己在使用过程中自然而然积累了对代码的理解。这时可以考虑：

- **学一点 HTML/CSS 基础** — 不是为了手写，而是为了能更准确地描述你想要的界面效果
- **了解项目结构** — 知道 `src`、`components`、`pages` 这些文件夹是干什么的，方便你对 AI 说"帮我在 components 下新建一个导航栏组件"
- **学 Git 基础** — 版本管理是协作的基础，学会 `git commit`、`git push` 就够了
- **了解部署流程** — Vercel、Netlify 这类平台让部署变得极其简单，值得一试

总结：Vibe Coding 不是让你不学编程，而是让编程的门槛降到你可以先动手做起来、在实践过程中边做边学。做好东西比背概念重要得多，当你看到你自己的应用真的跑起来了，你会更有动力主动学习"这个功能是怎么实现的"——这种动力驱动的学习效率是看教程的十几倍。
